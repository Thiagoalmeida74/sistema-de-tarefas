# Sistema de Tarefas

Sistema de gerenciamento de tarefas desenvolvido em Python, com funcionalidades para criação, listagem e busca de tarefas.

O projeto utiliza conceitos de Programação Orientada a Objetos (POO) e possui uma estrutura preparada para evolução das funcionalidades.

## Funcionalidades

- Criar tarefas
- Gerar ID automaticamente
- Definir prioridade
- Definir status inicial como Pendente
- Listar tarefas
- Buscar tarefas pelo título

## Tecnologias

- Python
- Programação Orientada a Objetos
- Git
- GitHub
